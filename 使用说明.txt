Faker 飞鼠桌宠 · v1.0.0

双击「Faker飞鼠桌宠.exe」启动。需要与 spritesheet.png 放在同一个文件夹。

交互方式
1. 待机：播放待机动画，飞鼠安静地呼吸、眨眼。
2. 鼠标移到飞鼠身上：头部转向鼠标所在方向（16 个方向）；移开后恢复待机。
3. 单击飞鼠：挥手打招呼。
4. 双击飞鼠：兴奋地跳跃一下。
5. 按住左键拖动：飞鼠朝移动方向奔跑，随移动方向轻微倾斜；松手后轻弹落地。
   支持拖到另一块屏幕，位置会自动保存。
6. 全屏时自动隐藏：默认开启。飞鼠所在屏幕的前台应用进入全屏后，
   飞鼠会自动隐藏；退出全屏或切走该应用后，在原位置恢复。
   普通窗口最大化，以及其他屏幕上的全屏，不会触发隐藏。

右键菜单
右键飞鼠或任务栏托盘图标，可使用以下功能：

| 菜单项 | 用途 |
| --- | --- |
| 跳跃（双击） | 播放跳跃动画。 |
| 挥手 | 播放挥手动画。 |
| 沮丧 | 播放沮丧动画。 |
| 大小 | 选择小号、标准或大号。 |
| 总在最上面 | 开启或关闭窗口置顶。 |
| 全屏时自动隐藏 | 开启或关闭全屏隐藏功能。 |
| 回到屏幕右下角 | 将飞鼠移回鼠标所在屏幕的右下角。 |
| 打开使用说明 | 打开本说明。 |
| 退出飞鼠 | 关闭桌宠。 |

「总在最上面」「全屏时自动隐藏」右侧有 ✓ 表示开启，没有对勾表示关闭。

找不到飞鼠时
再次双击程序，或双击任务栏托盘中的飞鼠图标，让它回到鼠标所在屏幕的右下角。
托盘图标可能收在任务栏的隐藏图标区域内。
如果此时仍处于全屏，飞鼠会继续隐藏；退出全屏即可看到。

设置保存位置
位置、大小、置顶与全屏隐藏设置保存在：
%LOCALAPPDATA%\FakerDesktopPet\settings.ini

素材说明
本桌宠使用 Faker 素材（Codex 桌宠 V2 精灵图集 spritesheet.png），
待机、奔跑、挥手、跳跃、沮丧及 16 个环视方向均直接取自原图集的对应动作，
未做重绘。素材版权与转载要求见同目录 ARTWORK-NOTICE.md。

运行环境：Windows 10 / 11 自带的 .NET Framework 4.x，本地运行，无需联网。
